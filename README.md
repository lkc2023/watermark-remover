# 🎬 视频去水印工具

支持短视频解析 + 上传视频去水印 + 手动标注 + 批量处理

## ✨ 功能

- 🔗 短视频解析（抖音/快手/小红书/B站/微博）
- 📤 上传自动去水印
- 🎨 手动标注去水印（画笔/矩形）
- 📦 批量处理
- 📊 进度显示

## 🚀 部署

### Railway 部署
1. Fork 本仓库
2. 访问 [Railway](https://railway.app)
3. 创建新项目，选择本仓库
4. 自动部署

### 本地运行
```bash
pip install -r requirements.txt
python main.py
```

访问 http://localhost:9099

## 📝 使用说明

1. 短视频解析：粘贴链接，点击解析
2. 上传去水印：上传图片/视频，选择自动或手动模式
3. 手动标注：用画笔涂抹水印位置，点击去除水印

## ⚠️ 注意事项

本工具仅供学习研究使用，请勿用于商业用途。
